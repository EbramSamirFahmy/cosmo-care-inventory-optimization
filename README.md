# COSMO IQ – Smart Inventory Optimization & Demand Forecasting

## Project Overview

COSMO IQ is an intelligent inventory optimization and decision support system developed for Cosmo Care.

The system integrates data analysis, demand forecasting, inventory optimization, and data visualization to support data-driven inventory planning and improve inventory performance.

## Objectives

- Forecast future product demand using historical sales data.
- Optimize inventory decisions and replenishment policies.
- Reduce stockout and overstock risks.
- Support management with data-driven insights.

## Project Workflow

The project follows an end-to-end analytical workflow:

**Data Collection → Data Cleaning → EDA → Demand Forecasting → Inventory Optimization → Sensitivity Analysis → Visualization & Decision Support**

## Methodology

### 1. Data Cleaning & Exploratory Data Analysis

Historical sales data from 2020–2024 was cleaned, prepared, and analyzed to identify sales patterns, seasonal trends, product behavior, and outliers.

### 2. Demand Forecasting

Two forecasting approaches were developed and evaluated:

- Prophet using the full 2020–2024 historical period.
- Linear Regression with a Dynamic Seasonal Index using 2022–2024 data.

Forecasting performance was evaluated using:

- MAE
- RMSE
- Error Ratio

### 3. Inventory Optimization

Inventory planning was supported using:

- ABC Classification
- Economic Order Quantity (EOQ)
- Reorder Point (ROP)
- Safety Stock
- Sensitivity Analysis

### 4. Visualization & Decision Support

Analytical results and inventory insights were presented through interactive Power BI dashboards to support management decision-making.
